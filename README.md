# Pulse Floor

A rhythm-based dance floor game built with Hytopia. Players can step on different colored tiles that light up to the beat of the music. Score points by hitting the right tiles at the right time!

## About the Game

Pulse Floor is an interactive rhythm game where players navigate a dynamic dance floor. The game features:

- Colorful light-up floor tiles that pulse with the music
- Score tracking and multipliers for consecutive hits
- Multiple difficulty levels
- Various visual effects and animations

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) (v1.2.8 or later) - A fast JavaScript runtime

### Installation

1. Clone the repository:
```bash
git clone https://github.com/MaddoxNehls/Pulse-Floor.git
```

2. Navigate to the project directory:
```bash
cd Pulse-Floor
```

3. Install dependencies:
```bash
bun install
```

### Running the Game

To start the game server:
```bash
bun run index.ts
```

After starting the server, open your web browser and go to `http://localhost:3000` (the exact port may be displayed in your terminal after running the command).
